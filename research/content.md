# 콘텐츠·미디어 기능 연구 메모

## 확인한 공식 자료

- [OWASP File Upload Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html): 허용 확장자 목록, Content-Type 불신, 파일 시그니처·크기 검증, 서버 생성 파일명, 웹 루트 밖 저장, 악성코드 검사, CSRF 방어 등 업로드 방어 심층화를 확인했다. 공개 파일 검색에는 다른 파일 노출·대량 다운로드·불법 또는 저작권 콘텐츠 호스팅 위험도 있다.
- [W3C WCAG 2.1](https://www.w3.org/TR/WCAG21/): 비텍스트 콘텐츠의 목적별 대체텍스트, 페이지·부분 언어의 프로그램적 식별, 키보드와 이해 가능한 인터페이스 원칙을 확인했다.
- [W3C Captions/Subtitles](https://www.w3.org/WAI/media/av/captions/): 자막은 음성·이해에 필요한 비음성 오디오의 동기화된 텍스트이며, 사전 녹화된 오디오 포함 영상에서 정확한 캡션이 필요하다는 점과 자동 캡션은 검수 전 완성본이 아니라는 점을 확인했다. WebVTT를 대표적인 웹 캡션 형식으로 안내한다.

## 적용 원칙

각 기능의 보안·개인정보·접근성·법률 필드는 위 공식 자료의 원칙을 기능별 흐름에 맞게 구체화했다. 법률 관련 문구는 관할과 사업 유형에 따라 달라질 수 있음을 명시하고 법률자문으로 단정하지 않았다.
