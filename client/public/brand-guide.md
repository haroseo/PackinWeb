# 패킨앱 브랜드 리소스

패킨앱은 웹서비스에 필요한 기능을 목적, 사용자 흐름, 구현 로직과 함께 살펴보도록 정리하는 프로젝트입니다. 현재 공개 사이트는 PackinWeb 이름으로 운영됩니다.

저장소에서 PackinApp 전용으로 승인된 로고 파일을 찾지 못해, 아래의 글자 로고와 조합 로고는 현재 PackinWeb 심벌과 제품 UI를 바탕으로 만든 시안입니다. 기존 `/logo.svg`와 공개 서비스 표기는 바꾸지 않았습니다.

## 1. 소개

- 프로젝트 이름: 패킨앱 (PackinApp)
- 현재 공개 서비스 표기: 패킨웹 (PackinWeb)
- 현재 공개 주소: <https://packinweb.pages.dev/>
- 설명: 웹서비스 기능을 목적, 흐름, 구현 로직과 함께 살펴보는 한국어 레퍼런스

## 2. 심벌 로고

- 파일: [`/brand/packinapp-symbol.svg`](https://packinweb.pages.dev/brand/packinapp-symbol.svg)
- 정사각형 비율을 유지하고 가로·세로로 늘이지 않습니다.
- 검정 바탕과 흰색 심벌의 대비를 유지합니다.
- 최소 24 × 24px으로 표시하고 심벌 너비의 1/4 이상 여백을 둡니다.
- 아이콘이나 프로필처럼 이름을 쓸 공간이 좁을 때 사용합니다.
- 배경 경계가 사라지는 환경에서는 검정 바탕이 있는 원본을 사용합니다.

## 3. 글자 로고

- 파일: [`/brand/packinapp-wordmark.svg`](https://packinweb.pages.dev/brand/packinapp-wordmark.svg)
- 영문 표기는 `PackinApp`으로 고정합니다.
- Pretendard Bold 계열을 기준으로 하며, 대소문자와 글자 간격을 임의로 바꾸지 않습니다.
- 표시 너비 96px 이상과 글자 높이 절반 이상의 주변 여백을 확보합니다.
- 배경과 충분한 대비를 확보합니다. 인쇄물에서 서체 대체가 우려되면 글자를 윤곽선으로 변환합니다.

## 4. 심벌 + 글자 로고

- 파일: [`/brand/packinapp-lockup.svg`](https://packinweb.pages.dev/brand/packinapp-lockup.svg)
- 심벌, 글자 크기 비율, 배치와 간격을 한 덩어리로 유지합니다.
- 최소 너비 160px과 심벌 높이의 절반 이상 여백을 확보합니다.
- 가로 공간이 부족하면 조합을 줄여 왜곡하지 말고 심벌 로고를 사용합니다.

## 5. OG 이미지

- PNG: [`/brand/packinapp-og.png`](https://packinweb.pages.dev/brand/packinapp-og.png), 1200 × 630px
- 편집 원본: [`/brand/packinapp-og.svg`](https://packinweb.pages.dev/brand/packinapp-og.svg)
- 링크 공유용 이미지로 사용하고 1.91:1 비율과 가장자리 여백을 유지합니다.
- 가장자리에서 60px 이상 안쪽에 제목과 심벌을 두어 미리보기 자르기에 대비합니다.
- 내용이나 대표 문구가 바뀌면 페이지 메타데이터와 OG 이미지도 함께 갱신합니다.

이 자료는 현재 코드와 시안을 설명합니다. 상표 등록, 제3자 권리 또는 브랜드의 법적 사용 가능성을 확인해 주는 문서가 아닙니다.
